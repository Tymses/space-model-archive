# Open-source licensing

SPACEMESHER uses separate licences for software and original documentation:

- **Source code — MIT License:** original HTML, CSS, JavaScript, Cloudflare Worker source, Python tools and other project code are released under the MIT License. See [LICENSE](LICENSE).
- **Original documentation — CC BY 4.0:** project-authored documentation and written guides are licensed under Creative Commons Attribution 4.0 International. See [LICENSE-DOCUMENTATION](LICENSE-DOCUMENTATION).

## What is not covered by these licences

SPACEMESHER is a source-linked catalogue. A model, image, dataset, texture, logo, scientific paper, external library or other third-party asset is **not** automatically relicensed by the project licences. The original publisher's terms apply. Each model record should retain its own source and licence information; when the licence is unknown, treat reuse as unknown and check the original source before redistribution.

The MIT licence also does not grant rights to third-party dependencies loaded by the site (for example, libraries loaded from a CDN). Their own licences continue to apply.

The CC BY notice applies only to original written documentation. It does not automatically apply to the contents of the data directory, because catalogue records can contain third-party metadata and source material with different terms. A separate, file-specific licence may be added to original datasets or assets after their provenance and rights have been checked.

## Attribution

When reusing original SPACEMESHER code, retain the copyright and licence notice as required by MIT. When reusing original SPACEMESHER documentation, credit SPACEMESHER, link to the source and [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), and indicate whether changes were made.
